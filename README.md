
DCS VREM is a mod for the game [DCS World](https://www.digitalcombatsimulator.com) based on [reshade](https://reshade.me/) [API](https://github.com/crosire/reshade/blob/main/REFERENCE.md).

It uses a reshade addon to modify the way the game renders images and improve the user experience, especially in VR.

For more information on the mod's usage and features, go to [https://forum.dcs.world/topic/356128-reshade-vr-enhancer-mod-2-vrem2/](https://forum.dcs.world/topic/356128-reshade-vr-enhancer-mod-2-vrem2/)


For more information on the mod itself and to understand how to modify it for other games, see the wiki.

VREM2 includes modified versions of popular shaders, optimized to affect only specific parts of the scene (Cockpit vs. External) or environmental elements (Sky, Sea…):

* **Technicolor2, Color Matrix, Fake HDR, & LumaSharpen** (by CeeJay.dk and Prod80)	
* **Deband** (by haasn)
